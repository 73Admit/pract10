# Практическая работа №10 — ML-продукт для анализа отзывов

Автор: Евсенин Даниил Павлович, группа П-2-23
Дисциплина: «Технология разработки и защиты баз данных»

ML-продукт решает задачу анализа отзывов клиентов интернет-магазина: классифицирует
тональность, защищает персональные данные, строит персональные рекомендации,
кластеризует отзывы и показывает аналитику в веб-интерфейсе.

## Данные

`data/reviews.csv` — **4 682 отзыва** покупателей интернет-магазина GameStop
(источник: [GameStop Customer Reviews](https://www.kaggle.com/datasets/thedevastator/gamestop-customer-reviews-dataset),
Kaggle). Поля, требуемые заданием, присутствуют все:

| Поле | Смысл |
|---|---|
| `text` | текст отзыва |
| `rating` | оценка от 1 до 5 |
| `product` | товар |
| `brand` | бренд |
| `date` | дата отзыва |
| `user_id`, `user_name` | пользователь |
| `verified`, `helpful` | признак проверенной покупки, число отметок «полезно» |
| `sentiment` | целевая переменная: 1 — позитив (оценка 4–5), 0 — негатив (1–3) |

123 товара, 70 брендов, период с 2009 по 2022 год, доля позитивных отзывов 84,9 %.
В исходных данных дата указана относительно момента сбора («2 years ago»), поэтому
в `tools/prep_pr10.py` она переведена в абсолютную относительно даты выгрузки 16.01.2022.

| Файл | Назначение |

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python train_models.py      # обучение моделей и подготовка артефактов (~10 минут)
python app.py               # веб-приложение на http://127.0.0.1:5001

```

## Что реализовано

**Классификация тональности.** Пять моделей на TF-IDF представлении: LogisticRegression,
RandomForest, XGBoost, MLPClassifier и CatBoost. Для каждой выполнен подбор
гиперпараметров через `GridSearchCV` не менее чем по трём параметрам; метрики
до и после подбора сведены в таблицу `models/metrics.csv` и выводятся на отдельной
странице сайта вместе с ROC-кривыми. Функция `predict_sentiment` возвращает
«позитивный»/«негативный» и процент уверенности.

**Защита персональных данных.** Функции `mask_phone`, `mask_email`, `mask_card`
и `mask_name` в `ml_core.py` заменяют телефоны, адреса почты, номера карт и имена
на заглушки. Маскировка применяется при загрузке датасета и перед сохранением
каждого нового отзыва; все четыре функции покрыты тестами.

**Аналитика.** Топ товаров по доле позитивных отзывов, самые частые слова
в негативных отзывах, средний рейтинг товара, распределение оценок, динамика отзывов
по кварталам, облако слов по всем и отдельно по негативным отзывам. Сводный отчёт
сохраняется в `student_report.png`.

**Персональные рекомендации.** Каждому посетителю при первом заходе выдаётся
идентификатор, который хранится в cookie-сессии. По матрице «пользователь × товар»
ищутся похожие пользователи (косинусная близость), и товары, которые они оценили
высоко, предлагаются текущему. Если оценок меньше двух, система показывает товары
с наибольшей долей позитива.

**Кластеризация.** Отзывы векторизованы моделью `sentence-transformers/all-MiniLM-L6-v2`
(384 измерения), затем применены KMeans и DBSCAN. Для каждого кластера выводятся
топ-10 слов и средняя тональность. Визуализация — интерактивный график Plotly
в проекции PCA; по кнопке рядом с кластером открываются примеры его отзывов.

**Журналирование.** Все обращения к веб-приложению пишутся в `app.log` (время, уровень,
идентификатор пользователя, действие, результат). Последние 50 записей доступны
на отдельной странице для разработчика.

**Тесты.** Восемь тестов pytest: маскировка телефона (три формата), маскировка имени,
почты и карты, отсутствие ложных срабатываний, структура датасета, предсказание
тональности, аналитические функции, корректность файла метрик, рекомендации
для нового пользователя, запись и чтение из базы и журнала.

## Страницы веб-интерфейса

| Адрес | Содержание |
|---|---|
| `/` | форма отзыва с предсказанием тональности, рекомендации, история своих отзывов |
| `/stats` | распределение оценок, динамика отзывов, облака слов, топ товаров, частые слова негатива |
| `/products` | статистика по товарам: средний рейтинг, количество отзывов, доля позитива |
| `/models` | сравнение пяти моделей до и после подбора параметров, лучшие параметры, ROC-кривые |
| `/clusters` | интерактивная визуализация кластеров, их характеристики и примеры отзывов |
| `/logs` | последние 50 записей журнала `app.log` |
